# 终端界面

`mena` 的 Agent 启动器、Session 浏览器、Skill 浏览器和 MCP 注册目录统一使用
**Calm Console（静雅控制台）**界面。它适合长时间、键盘优先的工作：信息可以快速
扫读，同时保持克制，全天打开也不会喧闹刺眼。

## 视觉语言

- `mena · 区域` 用自然语言标识当前位置；面板使用 `Sessions`、`Skills`、`Details`
  这类短而清楚的名称。
- 大面积背景采用中性炭灰；低饱和钢蓝表示焦点，柔和绿色表示成功，柔和琥珀色
  表示谨慎，低饱和红色仅用于错误和破坏性确认。
- 边框、表头和元数据弱于主要内容。状态使用小圆点标签，不用大面积色块抢夺注意力。
- 不使用装饰性动效。只有真实进行中的操作可以动画，阅读时界面保持稳定。
- 所有界面的快捷键都使用 `[按键] 操作` 语法；窄终端只显示主要操作，避免长
  Footer 被截断。
- 普通文本状态使用自然前缀 `mena:`、`done:` 和 `error:`。

Provider 图形保留轻微的身份色，但只用于识别；运行状态始终遵循上述语义色。

## 统一按键

同一个按键在所有浏览器中含义一致：

- `/` 始终只过滤已加载的字段，绝不扫描对话、绝不启动进程。
- `Enter` 打开选中项的主视图。
- `o` 打开原生产物：Skill 目录、MCP 源配置，或在配置的编辑器中打开记忆文件。
- `e` 只表示编辑原生配置，绝不表示导出。
- `p` 是唯一可能启动进程或访问网络的按键，且必须先弹出确认，展示
  selector、源文件和将要执行的内容，确认后才会运行。
- `d` 表示删除。确认弹窗会写明确切后果——Session 是移入回收站并说明恢复方式，
  MCP 和记忆文件是不可逆改写。
- `?` 打开当前界面的完整键位浮层；任意按键关闭。
- `1`–`4` 在 Sessions、Skills、MCP 和 Memories 之间直接切换，无需退回终端。

## 响应式布局

每次重绘都会根据终端尺寸调整布局：

- 小于 100 列时，Skill 的列表/预览、MCP 的列表/详情和记忆的列表/预览改为上下排列；
- 小于 88 列时，Agent 启动器隐藏优先级较低的 Session 上下文列；
- 小于 96 列时，Footer 收敛为主要快捷键；
- Session 表格在所有宽度下都把 `TARGET` 保持为第一列，详情保持独立滚动。

Footer 只展示主要操作；`?` 始终可以展开完整键位，窄终端损失的是可发现性，
不是能力。

布局重排不会改变全屏详情、列表选中、搜索、鼠标/键盘滚动和确认逻辑。

## Session 详情颜色

Calm Console 调色板是默认值。仍可通过 `[ui.session_detail.colors]` 单独覆盖 Session
详情中的每一类文本；已有自定义配置继续优先生效。参见[配置](configuration_CN.md)。

## 终端支持

界面使用 Unicode 线框字符和 RGB 色彩。现代终端会直接呈现目标调色板，颜色空间较小
的终端可能做近似映射。Session 详情仍保留终端原生文本选择与 `Command+C`。
