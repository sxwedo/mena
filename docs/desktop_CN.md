# 原生 macOS 应用

桌面应用使用 SwiftUI 和 AppKit，复用 mena 现有的 Rust Catalog。
运行需要 macOS 14 或更新版本；构建需要 Xcode 26 / Swift 6.2 或更新版本、
Rust 1.96.1 和 Xcode 命令行工具。首次构建会下载 UniFFI 和 SwiftTerm；
应用无需账号、守护进程或远程数据存储。

## 构建与运行

```sh
mise run gui                     # 构建并打开
mise run gui-build               # 只构建
mise run gui-release             # 优化后的应用
open target/macos/Mena.app
```

应用生成在 `target/macos/Mena.app`，包含所需的 Rust 动态库，并使用临时签名
供本地开发。可以将应用复制到 `/Applications` 或 `~/Applications`，再用
`mena gui` 打开。安装 CLI 不会自动安装桌面应用。面向公众分发时，还需要
Developer ID 签名和公证。

macOS release 构建会关闭 Rust 的调试信息裁剪，避免当前固定工具链生成的 Mach-O
字符串表被 Xcode 27 链接器拒绝（[上游问题](https://github.com/rust-lang/rust/issues/157750)）。
动态库的安装路径在链接时确定。

## 工作区

- 三栏分别展示项目与功能导航、当前目录列表和详情。会话支持按 Provider、项目、
  标题、会话标识和消息内容搜索。新搜索会取消过时的工作，详情选择始终跟随筛选结果。
- SubAgents 初始隐藏；列表底部的开关会记住偏好。标签区分 SubAgent 和原生分支，
  会话信息中可以跳转到当前目录里存在的父会话。
- 点击消息卡片选中消息；焦点在对话区域时，也可以用方向键切换。选中状态使用
  薄荷色标记、边框和“分叉起点”标签；搜索命中使用独立的黄色高亮。
  USER 气泡靠右，Agent 气泡靠左。只有用户与助手消息能分叉，工具、Skill、系统与错误记录不能分叉。
- 默认展示用户和助手消息，可通过顶部按钮或菜单一键开启**简化会话**（仅保留用户的原生问题和 AI 的最终回答，隐藏 SKILL、工具调用与结果、系统记录及思考过程），也可通过菜单显示完整的工具与系统记录。会话改名仅写入 mena
  自己的标题覆盖层，不修改 Provider 的原始会话。
- 会话消息和 Markdown 资源预览支持标题、嵌套列表、任务列表、引用、表格、行内
  格式与可复制的代码块。菜单中可以查看源码、调整阅读字号，设置会记住字号。
  内嵌图片仅显示说明文字，不自动下载；底部按钮可以跳到首条或最新消息。
- 项目按最近会话排序，默认展示八项，可以展开全部项目。会话标识集中放在信息面板，
  长用户消息默认收起，按需展开。
- 资源页优先展示正文，来源信息可以展开；Skill 元数据仅在源码中展示，不再作为大标题渲染。
- Agents 资源页列出内置与配置的自定义 Agent，展示安装状态、可执行文件、官方文档，
  并提供开始新对话与查看会话的入口。
- Skills、MCP 和 Memories 复用 CLI 的 Catalog 与有界读取。选择项目可以包含
  项目级资源。MCP 发现保持静态；只有主动点击“探测服务”才会启动配置的服务或
  连接端点。探测只返回元数据，结果始终关联到发起探测的注册项。
- 运行中进程只有在当前 Provider 原生证据确认关联时，才提供会话跳转。

侧栏与设置支持跟随系统、浅色和深色外观。`⌘R` 刷新目录，返回工作区时也会
刷新。`⌘K` 搜索列表，`⌘F` 搜索消息，`⌘⇧F` 打开消息分叉，`⌘Return` 继续会话。
`⌘⇧L` 切换全屏聊天界面（折叠侧边栏与列表，仅展示聊天窗口；会话详情顶栏亦提供全屏切换按钮，按 `Esc` 可快速退出全屏）。
应用图标和侧栏使用 README 图片的静态首帧，以头肩近景裁切展示，减少留白、放大头像。

设置提供薄荷、海盐、鸢尾、琥珀和石墨五套配色。可以导入本地 PNG、JPEG、HEIC 或 TIFF
背景，分别调整图片强度、模糊和面板不透明度，文字保持不透明。图片限 20 MB，显示时
缩采样至最大 4096 像素，并私有复制到 mena 的桌面状态目录。`⌘⌥S` 单独收起或恢复侧边栏，
应用会记住状态。

## 删除与恢复

通过会话行右键菜单或详情菜单删除。设置中可选择默认移入 **mena 垃圾站**（初始默认），
或彻底删除原生文件与关联索引。确认弹窗固定此次删除方式，只有准确输入小写 `y` 才能操作。
两种方式都会重新核对当前运行证据；关联不明确或存在歧义时，保护该 Provider 的整个目录。

垃圾站列出可恢复会话，可恢复原生文件和 mena 显示名称。恢复不会覆盖已有文件，也拒绝
Provider 存储范围以外的路径。彻底删除不保留可恢复记录；原生清理失败时，为已移动的文件
保留恢复清单。CLI 删除始终使用垃圾站，不受桌面偏好影响。

## 导出 Markdown

点击会话详情顶部的导出按钮，或按 `⌘⇧E`，然后选择文件夹。
导出范围跟随当前消息视图：默认只导出用户与助手消息；开启“显示工具与系统记录”
后导出完整记录。操作通过 Catalog 重新读取原生会话，复用 CLI 的 Markdown 导出器。
文件使用私有权限（Unix 下为 `0600`），不会覆盖已有文件；完成提示提供“在 Finder 中显示”。

## 新建、继续会话与消息分叉

点击“新对话”或按 `⌘N`，选择已安装的内置或配置的自定义 Agent 和项目目录。
应用复用 CLI 的原生启动参数，打开独立终端；会话由 Agent 启动后自行保存，
不会向目录添加虚假的占位会话。

继续会话先弹窗展示准确的原生恢复命令和工作目录，支持复制命令与选择终端。可选择
mena 内置终端，或已安装的 Terminal、iTerm2、Ghostty、WezTerm，并记为默认恢复终端；
设置中也能修改。Ghostty 可能在自己的窗口中要求执行确认，mena 不绕过该确认。
请求交给外部终端后，进程由该终端管理，退出 mena 不会停止它。新对话与消息分叉使用内置终端。
Agent 尚未安装或项目目录不存在时，仍可查看、复制恢复命令，直接启动会保持禁用。

程序、参数数组和
工作目录分别传递，不拼接 shell 命令。可执行文件定位会补充常见用户目录和
Homebrew 路径，以适应 Finder 较少的 PATH。关闭仍在运行的内置终端或退出应用时，
需要确认停止由应用启动的进程。
外部恢复通过已签名的原生启动器读取私有、一次性的 JSON 请求，以参数数组调用 `exec`，
随后移除请求文件；界面复制时使用的引号格式不会用于执行。

分叉弹窗明确区分两种方式：

1. **原生分叉**：仅在 Provider 支持且有持久化完整回合边界的位置可用，目前为
   Codex。创建截至该回合的独立原生会话，并保存其显示名称。
2. **携带上下文新建**：将截至选中消息的标准化历史交给已安装的 Claude、Codex
   或 Oh My Pi，以新进程开始独立对话。工具运行状态与原生会话状态不继承。
   填写的名称用于终端窗口，目标 Agent 在启动后生成自己的原生会话。

两种方式都会重新读取历史，发现消息或此前上下文发生变化时拒绝继续，后续消息
不会带入。上下文 handoff 使用私有临时文件，由准备好的启动对象持有，并在终端
进程运行期间保留。原会话保持完整。

## 实现与验证

`src/desktop.rs` 是可选 `desktop` feature 的强类型接口；
`src/desktop/model.rs` 定义跨接口的数据，`resources.rs` 整理脱敏目录元数据，
`launch.rs` 持有启动参数和上下文文件。Provider 存储逻辑保留在原有适配器中。
UniFFI 将 Swift 绑定生成到忽略的 `macos/Generated/`，不要编辑生成文件。

`macos/Sources/Mena/WorkspaceModel.swift` 管理界面选择、请求代次和偏好。
阻塞的 Rust 调用在主 actor 之外执行，过时的返回不会覆盖当前选择。
SwiftUI 页面按工作区、会话、资源和操作弹窗拆分；
`TerminalWindows.swift` 管理终端进程生命周期。`MessageFormatting.swift` 使用 Foundation
原生 Markdown 解析器，将块级结构排版为 SwiftUI 视图，不额外引入解析依赖或 WebView。

```sh
mise run verify      # 原有 CLI 验证
mise run gui-verify  # CLI、桌面 Rust 检查、原生测试、格式及 debug/release 构建
```

原生模型测试使用临时 Provider 存储和独立偏好。手动测试时可用
`MENA_GUI_HOME` 指向样例用户目录，并使用独立的桌面偏好；它不会改变 `HOME`，也不会改变 Provider
命令自己的配置目录。直接运行应用时，可以传入 `--workspace /绝对项目路径`。

原生窗口还需要实际检查：搜索、切换外观、提交两种分叉、启动新 Agent，
以及显式探测样例 MCP 服务。切换专注阅读后，确认 `⌘K` 能恢复列表并聚焦搜索框；
缩小至最小窗口宽度，确认正文正常换行。操作结束后，空闲 CPU 应回落且界面持续响应。
这些检查覆盖模型测试没有创建的 AppKit 布局和进度控件；原生控件直接使用已解析的主题色，
避免动态颜色触发布局循环。MCP 页面优先展示连接与探测概况，原始元数据按需展开。

这一版提供浏览、改名、继续会话、消息分叉、Markdown 导出、删除和垃圾站恢复。
配置修改仍可通过 CLI/TUI 使用。
