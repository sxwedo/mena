# Project skills

Codex discovers repository-scoped skills from `.agents/skills/` while working
inside this repository. Invoke a skill explicitly with its `$name`, or let
Codex select it from the description in its `SKILL.md`.

## Installed skills

- `ponytail`: prefer the smallest correct implementation, with YAGNI, the
  standard library, and native platform features first.

The vendored skill comes from
[`DietrichGebert/ponytail`](https://github.com/DietrichGebert/ponytail), path
`skills/ponytail`, pinned at commit
`16f29800fd2681bdf24f3eb4ccffe38be3baec6b`. It is distributed under the MIT
license included beside the skill.
